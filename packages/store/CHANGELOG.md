# Changelog

## [1.0.0] - 2026-06-14

FAN 1.0.0 — стабилизация FAN Store. Менеджер пакетов для расширений, навыков
и тем в production-ready состоянии.

### Новое

- **Стабилизация API** — финализированы все 5 LLM-инструментов
- **SHA-256 верификация** — проверка целостности загружаемых пакетов
- **Path traversal protection** — защита от выхода за пределы директории установки
- **Backup & rollback** — автоматическое резервное копирование при установке
- **Repository management** — multi-repo поиск, file:// URL, offline mode
- **Bundle support** — установка из архивов (extensions/, skills/, themes/)

### Улучшения

- **Полная адаптация pi-store v1.7.1** — надёжный движок управления пакетами
- **Миграция на `fan.sea-agents.ru/fan-store`** — новый репозиторий по умолчанию
- **Интерактивный браузер пакетов** — `/store browse` с навигацией
- **Анимация операций** — install/remove/update с визуальной обратной связью
- **Показ локально установленных пакетов** — отображение пакетов не из удалённого индекса
- **Отключение autoload** для dotenv и package.json при сборке

### Исправления

- Переписан установщик: bun CLI, staging, очистка workspace deps
- `--ignore-scripts` для пропуска сборки native модулей
- Авто-установка bun CLI, если не найден
- Очистка .bak файлов после успешной установки
- Staging/backup вынесены из директории extensions
- Windows: скрытие окна терминала при self-update
- `rsync` без `--delete` — чтобы не терять пакеты при публикации

## [0.3.4] - 2026-04-17

### Новый пакет: @fan/store — FAN Store Extension

- **5 LLM-инструментов**: store_search, store_install, store_remove, store_update, store_list
- **`/store` slash-команда** с подкомандами (search, install, remove, update, list, browse)
- **Управление репозиториями** — добавление, удаление, переключение
- **Multi-repo поиск** — поиск пакетов во всех подключённых репозиториях
- **Установка из архивов** — .tar.gz, .tgz, .zip
- **Bundle support** — установка директориями (extensions/, skills/, themes/)
- Базовая верификация и защита
