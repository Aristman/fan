# Changelog

## [1.0.0] - 2026-06-14

FAN 1.0.0 — стабилизация Model Manager. Маршрутизация провайдеров,
fallback-цепочки и учёт бюджета в production-ready состоянии.

### Новое

- **Стабилизация API** — финализирован интерфейс ProviderRouter, FallbackChain, BudgetTracker
- **Refresh моделей** перед `getAvailable` — актуальный список провайдеров при каждом запросе
- **Индивидуальные настройки провайдеров** — ModelSettings через @fan/db
- Полная интеграция с @fan/db (ModelSetting, Budget таблицы)

### Улучшения

- ProviderRouter — маршрутизация запросов к правильному LLM-провайдеру
- FallbackChain — цепочки провайдеров с резервными вариантами
- BudgetTracker — отслеживание дневных и месячных лимитов
- Поддержка 10+ провайдеров: OpenAI, Anthropic, Google, Mistral, DeepSeek и др.
