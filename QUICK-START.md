# Quick Start — FAN

> **FAN (Filin Agent Next)** — локальный AI-агент для разработчиков. Работает прямо на вашей машине, подключается к
> любым AI-провайдерам (OpenAI, Anthropic, Google, Groq и 40+ других), управляет моделями, запускает мультиагентные
> воркеры и предоставляет веб-дашборд.

## Установка

Одна команда — всё остальное скрипт сделает сам (определит ОС, скачает бинарник, проверит чексумму, добавит в PATH):

```bash
# macOS / Linux
curl -fsSL http://185.219.41.46/fan/dist/install.sh | bash

# Windows (PowerShell)
irm http://185.219.41.46/fan/dist/install.ps1 | iex
```

## Первичная настройка

```bash
fan init          # Интерактивный мастер: API-ключи, модель по умолчанию, предпочтения
fan doctor        # Проверка установки и зависимостей
```

## Основные команды

```bash
fan               # Интерактивный TUI-режим (по умолчанию)
fan -p "prompt"   # Один запрос (без интерактива)
fan --web         # Сервер + дашборд (откроет браузер)
fan update        # Обновить до последней версии
```

### Сервер (для IDE-плагинов)

```bash
fan server                # Сервер в foreground
fan server start          # Фоновый демон
fan server start --port 3000  # Кастомный порт
fan server status         # Статус (--json для машинного вывода)
fan server stop           # Остановить демон
```

### Хранилище скиллов и расширений

```bash
fan store list            # Установленные пакеты
fan store search <query>  # Поиск по магазину
fan store install <name>  # Установить скилл / расширение
fan store update          # Проверить обновления
```

## Хоткеи TUI

### Навигация и ввод

| Клавиша       | Действие                                 |
|---------------|------------------------------------------|
| `Enter`       | Отправить сообщение                      |
| `Shift+Enter` | Новая строка                             |
| `Escape`      | Прервать / отмена                        |
| `Ctrl+C`      | Очистить поле ввода                      |
| `Ctrl+D`      | Выход (если поле пустое)                 |
| `Ctrl+V`      | Вставить изображение из буфера           |
| `Ctrl+G`      | Открыть во внешнем редакторе (`$EDITOR`) |

### Редактор текста

| Клавиша                    | Действие                           |
|----------------------------|------------------------------------|
| `Ctrl+A` / `Home`          | В начало строки                    |
| `Ctrl+E` / `End`           | В конец строки                     |
| `Ctrl+W` / `Alt+Backspace` | Удалить слово назад                |
| `Ctrl+K`                   | Удалить до конца строки            |
| `Ctrl+U`                   | Удалить до начала строки           |
| `Ctrl+Y`                   | Вставить последний удалённый текст |
| `Ctrl+-`                   | Отменить                           |

### Модели и отображение

| Клавиша     | Действие                              |
|-------------|---------------------------------------|
| `Ctrl+L`    | Выбор модели                          |
| `Ctrl+P`    | Следующая модель                      |
| `Ctrl+T`    | Свернуть/развернуть блок thinking     |

### Сессии

| Клавиша  | Действие             |

## Slash-команды

Вводятся прямо в строке чата:

| Команда         | Описание                    |
|-----------------|-----------------------------|
| `/new`          | Новая сессия                |
| `/clear`        | Очистить контекст           |
| `/model <name>` | Сменить модель              |
| `/compact`      | Сжать историю сессии        |
| `/undo`         | Отменить последнее действие |
| `/tree`         | Дерево сессий               |
| `/fork`         | Форкнуть текущую сессию     |
| `/resume`       | Возобновить сессию          |
| `/skill:<name>` | Вызвать скилл               |

## Скиллы (встроенные)

| Скилл           | Назначение                                            |
|-----------------|-------------------------------------------------------|
| `auto-tests`    | Генерация тестов (8 языков)                           |
| `bug-fix`       | Автофикс багов: воспроизвести → исправить → проверить |
| `code-research` | Глубокий анализ кода (read-only)                      |
| `repo-explorer` | Анализ Git-репозитория (GitHub / локальный)           |
| `idea-lab`      | Исследование идей: SWOT, альтернативы, план действий  |
| `smoke-tester`  | E2E тестирование UI через Playwright                  |
| `fan-forge`     | Создание расширений и скиллов для FAN                 |

Полный список: `/skill:` → `Tab` для автодополнения.

## Мультиагентный оркестратор

FAN умеет делегировать задачи специализированным воркерам:

```
# Пример: исследовать → спланировать → реализовать
/plан "добавить dark mode в дашборд"
```

| Воркер         | Назначение                |
|----------------|---------------------------|
| 🔍 `explore`   | Быстрый поиск по коду     |
| 📋 `plan`      | Планирование архитектуры  |
| 🔧 `implement` | Написание кода            |
| 🛡️ `verify`   | Проверка, ревью, тесты    |
| 🐛 `bug-fix`   | Поиск и исправление багов |
