## Правила формулирования вопросов

1. **Максимум 5 вопросов за раунд** — больше утомляет пользователя
2. **Начинать с 🔴 блокирующих** — они наиболее критичны
3. **Группировать по темам** — не прыгать между измерениями хаотично
4. **allowOther: true** — всегда давать возможность свободного ответа
5. **Адаптировать к контексту** — не задавать вопросы, ответы на которые уже есть в спеке
6. **Не задавать «почему»** — это ведёт к долгим дискуссиям. Лучше «что» и «как»
7. **After each round** — пересчитать оценку и показать прогресс пользователю
