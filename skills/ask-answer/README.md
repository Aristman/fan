# ask-answer 🗣️

**Skill для интерактивного диалога с пользователем через TUI.**

Предоставляет два инструмента для взаимодействия: `question` (один вопрос с вариантами) и `questionnaire` (серия вопросов с таб-навигацией). TUI рендерит полноценный интерфейс — стрелки для навигации, Enter для выбора, Esc для отмены.

---

## Что это

ask-answer — это skill, который регистрирует два custom tool для LLM:

| Инструмент | Назначение | Когда использовать |
|------------|-----------|-------------------|
| **`question`** | Один вопрос с вариантами ответа | Подтверждение действия, выбор из 2-7 вариантов, уточнение предпочтений |
| **`questionnaire`** | Серия вопросов с таб-навигацией (Tab/←→) | Сбор нескольких ответов за один round-trip |

Не является extension — использует extension `ask-answer` (`~/.fan/agent/extensions/ask-answer/index.ts`) для регистрации tools, а SKILL.md содержит инструкции для LLM по их использованию.

---

## Как использовать

### Вызов

Skill активируется автоматически. Когда LLM вызывает `question` или `questionnaire`, TUI рендерит интерактивный UI.

### Для LLM — паттерны использования

**Подтверждение действия:**
```
question("Удалить все логи из /tmp/logs?", ["Да, удалить", "Нет, оставить"])
```

**Выбор подхода:**
```
question("Какую архитектуру используем?", [
  "Clean Architecture — слои: domain → data → presentation",
  "MVVM — Model-View-ViewModel с Repository",
  "MVI — Unidirectional data flow, Intent → State"
])
```

**Множественный выбор:**
```
questionnaire([
  { id: "framework", prompt: "Какой UI-фреймворк?", options: ["Jetpack Compose", "XML Views"] },
  { id: "di", prompt: "Какой DI?", options: ["Hilt", "Koin", "Dagger 2"] }
])
```

## Требования

- **fan** с поддержкой custom extensions
- TUI-режим (интерактивная сессия)
- Для активации после установки: `/reload`

---

## Принципы

- **Всегда с опцией свободного ввода** — последний вариант "Type something..." для свободы
- **Краткость** — вопрос в одну строку, описание — максимум полстроки
- **Действуй, потом спрашивай** — если уверен, делай. Спрашивай только при осмысленных альтернативах
- **Не спрашивай то, что можешь решить сам**
