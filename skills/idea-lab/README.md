# idea-lab 💡

**Skill для глубокого исследования и анализа идей любого типа.**

Превращает размытую мысль в структурированный документ с решениями и планом действий. Проводит оценку неопределённости, интервьюирование, веб-исследование, SWOT-анализ и брейншторм альтернатив.

---

## Что это

idea-lab — это skill, который проводит идею через полный цикл исследования:

```
Идея → Определение типа → Оценка неопределённости → Сбор информации → SWOT + Брейншторм → Документ
```

### Поддерживаемые типы идей

| Тип | Примеры | Фокус анализа |
|------|---------|---------------|
| **Техническая** 🛠️ | Фичи, архитектура, технологии | Реализуемость, стек, риски, tradeoffs |
| **Бизнес** 💼 | Стартапы, рынки, монетизация | Рынок, конкуренты, unit economics, MVP |
| **Креативная** 🎨 | Контент, дизайн, маркетинг | Аудитория, формат, каналы, KPI |

---

## Как использовать

### Запуск

```
/skill:idea-lab
```

Затем опиши свою идею на естественном языке.

### Примеры запросов

```
Хочу сделать CLI-тул для генерации mock-данных для REST API
```

```
Может стоит сделать SaaS для автоматического code review?
```

```
Нужен план по миграции с Java на Kotlin в нашем Android-приложении
```

### Глубина исследования

Skill предлагает три уровня глубины:

| Уровень | Время | Описание |
|---------|-------|----------|
| **Quick scan** | 3–5 мин | Быстрый анализ, минимальный опрос |
| **Стандартный** | 10–20 мин | Основное исследование |
| **Глубокий** | 30+ мин | Несколько циклов исследования |

## Процесс

1. **Инициализация** — фиксация идеи, определение типа, выбор глубины
2. **Оценка неопределённости** — матрица пробелов знаний (🔴🟡🟢) и матрица рисков
3. **Сбор информации** — циклический: опрос пользователя + веб-исследование + память проекта
4. **Анализ** — SWOT, брейншортм ≥3 альтернатив, сравнительная матрица, рекомендация
5. **Подтверждение** — пользователь решает: создавать документ, уточнить или сменить подход
6. **Финальный документ** — полный, самодостаточный отчёт на русском языке

---

## Принципы

- **Цикличность.** Исследование → вопросы → исследование → ... до полноты
- **Брейншторм всегда.** Минимум 3 альтернативы, даже если ответ очевиден
- **SWOT обязателен.** Для любого типа идеи
- **Честность.** Если идея херня — скажи с аргументами
- **Конкретика.** Не «возможно стоит рассмотреть», а «рекомендую X потому что Y»
- **Финальный документ** — без TODO, полный и самодостаточный
