# Strategy: Creative Ideas

Используется для: контент-стратегии, дизайн, брендинг, маркетинговые кампании, медиа-проекты, форматы.

---

## Ключевые аспекты для исследования

| # | Аспект | Что выясняем | Типичная неопределённость |
|---|--------|-------------|--------------------------|
| 1 | **Цель** | Что хотим достичь? (awareness, конверсия, лояльность) | Высокая — часто размыта |
| 2 | **Аудитория** | Кто потребляет? Возраст, интересы, платформы? | Высокая — критична для формата |
| 3 | **Формат** | Какой тип контента/решения? | Средняя — есть выбор |
| 4 | **Каналы** | Где публикуем/распространяем? | Средняя — зависит от аудитории |
| 5 | **Тональность и стиль** | Как звучим? Визуальный стиль? | Средняя — требует референсов |
| 6 | **Тренды** | Что работает сейчас в нише? | Средняя — нужен поиск |
| 7 | **Ресурсы** | Что можем произвести? (бюджет, время, навыки) | Высокая — constraints |
| 8 | **KPI / Метрики** | Как измеряем успех? | Высокая — определяет формат |

---

## Специфичные вопросы для интервью

### Блокирующие
- Какую конкретную цель преследует эта идея? (awareness / leads / sales / engagement / loyalty)
- Кто целевая аудитория? Опишите максимально детально.
- Какие каналы планируете использовать?
- Какой бюджет/ресурсы доступны?

### Важные
- Есть ли референсы / примеры / inspiration?
- Какой стиль/тональность? (формальный, неформальный, провокативный, minimal...)
- Сроки? (разовый релиз / регулярный контент / кампания)
- Есть ли brand book / гайдлайны?

### Рекомендательные
- Какие форматы контента уже пробовали?
- Есть ли данные по прошлым кампаниям/контенту?
- Кого привлекаем? (дизайнер, копирайтер, видео...)
- Какая частота выпуска?

## Специфичные критерии брейншторма

Для креативных альтернатив оценивай по:

| Критерий | Описание |
|----------|----------|
| Соответствие цели | Насколько формат/идея решает поставленную цель |
| Захват внимания | Насколько выделяемся в информационном шуме |
| Вирусный потенциал | Likelihood of organic sharing |
| Производственная сложность | Требуемые ресурсы, навыки, время |
| Масштабируемость | Можно ли воспроизводить регулярно |
| Измеримость | Насколько легко отследить KPI |
