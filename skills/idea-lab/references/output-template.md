Этот шаблон используется всеми стратегиями. Заполни на основе собранных данных.

---

## Формат имени файла

```
docs/research/idea-lab/<kebab-case-slug>/<Человекочитаемое название>.md
```

Примеры:
- `docs/research/idea-lab/rust-api-gateway/Rust API Gateway — анализ идеи.md`
- `docs/research/idea-lab/saas-mentorship/SaaS платформа менторства — исследование.md`

## Правила оформления

1. **Самодостаточность** — документ должен быть понятен без контекста сессии
2. **Конкретика** — не "нужно подумать", а "рекомендую X по причине Y"
3. **Данные** — каждое утверждение с источником или расчётом
4. **Ссылки** — все URL кликабельны и рабочие
5. **Таблицы** — используем для сравнений и структурированных данных
6. **Emojis** — минимально, для визуальной навигации по секциям
7. **Без TODO** — все разделы заполнены. Если данных нет — так и напиши "Данные отсутствуют"
8. **Язык — русский.** Каждое предложение грамматически русское. Технические термины, API и имена собственные оставляются по-английски. Английских идиом и фраз в русском тексте быть не должно. Концепции объясняются по-русски: «режим планирования» вместо «plan mode», «воркер» вместо «worker», «проверка реализации» вместо «verification pipeline».
9. **Заголовки таблиц** — по-русски. Содержимое ячеек — по-русски, кроме имён файлов, API-вызовов и имён собственных.
10. **Артефактные понятия сродненного английского** — переводить и использовать в русской грамматике: coordinator → координатор, worker → воркер, spawn → запуск/порождение, prompt → промпт, verification → верификация, routing → маршрутизация.
