# Report Template — Шаблон отчёта исследования

Справочник для Фазы 7 repo-explorer. Полный шаблон отчёта и правила генерации.

---

## Выходной формат

Сохраняй в `docs/repo-research/<repo-name>/<Название исследования>.md` по конвенции проекта.

Для GitHub: `<owner>-<repo>` (например, `facebook-react`)
Для локальных: имя директории репозитория

## Правила генерации отчёта

1. **ASCII tree** — глубина максимум 3 уровня, показывай только папки и ключевые файлы (manifests, entry points). Подпапки с количеством файлов в скобках: `src/ (45 files)`.
2. **Mermaid diagram** — только если есть >2 модулей. Не делай слишком детальным — уровень модулей, не файлов.
3. **Key modules** — не более 5-7 модулей. Выбирай самые важные.
4. **Следующие шаги** — предлагай конкретные действия для понимания кодбазы.
