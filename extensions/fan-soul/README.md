# fan-soul

Динамическое управление личностью агента и профилем оператора для FAN.

## Возможности

- **SOUL.md** — файл личности агента (имя, характер, стиль общения, границы)
- **USER.md** — профиль оператора (имя, часовой пояс, контекст, предпочтения)
- **Автообучение** — извлечение фактов из диалога каждые 5 turns
- **Умное слияние** — дедупликация при обновлении секций USER.md
- **Интерактивная настройка** — `/soul init` проводит диалог для заполнения данных

## Установка

```bash
fan store install fan-soul
```

## Использование

### Первичная настройка

После установки запустите:

```
/soul init
```

Мастер настройки задаст вопросы о личности агента и вашем профиле:
- Имя и эмодзи агента
- Основная идентичность, стиль, границы, характер
- Ваше имя, как к вам обращаться
- Часовой пояс, язык
- Рабочий контекст

### Команды

| Команда | Описание |
|---------|----------|
| `/soul init` | Интерактивная настройка SOUL.md и USER.md |
| `/soul status` | Текущее состояние файлов |
| `/soul soul` | Предпросмотр SOUL.md |
| `/soul user` | Предпросмотр USER.md |
| `/soul edit` | Открыть редактор SOUL.md |
| `/soul drafts` | Список черновиков (существенные факты) |
| `/soul migrate` | Миграция USER.md в секционный формат |
| `/soul reset <soul\|user>` | Сброс файла к шаблону |

### Tool: soul_update

Агент может обновлять SOUL.md и USER.md через tool:

- `target`: `"soul"` | `"user"`
- `section`: имя секции (для user: profile, context, preferences, projects; для soul: core, style, boundaries, vibe)
- `action`: `"append"` | `"replace"` | `"remove"`
- `content`: текст для обновления

## Как это работает

### Lifecycle hooks

1. **session_start** — парсит identity из SOUL.md, показывает статус-виджет, проверяет миграцию USER.md. Если файлы отсутствуют — предлагает запустить `/soul init`
2. **before_agent_start** — инжектирует SOUL.md + USER.md в system prompt
3. **turn_end** — каждые 5 turns анализирует последние сообщения и извлекает факты

### Автообучение

Из диалога автоматически извлекаются:
- **Предпочтения** (trivial) — сразу записываются в USER.md
- **Решения** (substantial) — добавляются в черновики для подтверждения
- **Инструкции** (substantial) — добавляются в черновики
- **Контекст** (trivial) — сразу записываются

### Файлы

| Файл | Путь | Макс. размер |
|------|------|-------------|
| SOUL.md | `~/.fan/SOUL.md` | 4000 символов |
| USER.md | `~/.fan/USER.md` | 2000 символов |

- Импорты: `@mariozechner/pi-coding-agent` → `@itone/fan-coding-agent`

- Пустые шаблоны без записей по умолчанию
