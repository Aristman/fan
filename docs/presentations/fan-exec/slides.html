FAN — локальная AI-платформа
для разработки

Fast Agents Network: многоагентный ИИ-ассистент, который живёт на машине разработчика, а не в чужом облаке. Читает и пишет код, запускает тесты, чинит баги, пишет документацию — автономно.

Контекст и решение

Разработчикам нужен ИИ.
Но корпоративный код — не для чужих серверов.

🔒 Приватность

Облачные AI-ассистенты отправляют код и контекст на сторонние серверы. Для многих компаний это неприемлемо.

🧩 Фрагментация

Инструменты разрознены: чат в браузере, плагин в IDE, CLI — у каждого свой контекст и свои ограничения.

💸 Неконтролируемые расходы

Токены сгорают без лимитов и прозрачности. Никто не знает, сколько стоит одна решённая задача.

FAN закрывает все три боли

Один локальный рантайм объединяет терминал, веб-панель и IDE. Данные не покидают машину, расходы на ИИ — под контролем.

100% локальные данные Многоагентный оркестратор 20+ ИИ-провайдеров Windows · Linux · macOS

Ключевая фича

Оркестратор: команда ИИ-агентов
вместо одного чат-бота

  • Координатор разбивает задачу на подзадачи и контролирует исполнение
  • 8 специализированных воркеров explore · plan · implement · verify · bug-fix · code-research · tests-impl · docs-impl
  • Верификация после каждого шага adversarial-проверка результатов
  • Retry / fallback до 3 попыток с анализом ошибок

Сложная задача «исследуй → спланируй → реализуй → протестируй» решается автономно, как мини-командой разработки.

Экономика

Контроль расходов на ИИ —
встроен, а не прикручен

🎯 Роутинг моделей

Каждая задача идёт к оптимальной модели: дешёвой — для простого, мощной — для сложного.

💰 Budget Tracker

Дневные и месячные лимиты по токенам и стоимости. Визуализация бюджета в Dashboard.

🔄 Fallback-цепочки

Сбой провайдера или превышение лимита → автоматическое переключение на резервную модель.

Итог: предсказуемый счёт за ИИ и отсутствие простоев из-за одного провайдера.

Как этим пользуются

КлиентСценарий

Экосистема

FAN Store: платформа растёт
без изменения ядра

🧩 10 расширений

Включая оркестратор, вынесенный из ядра в standalone-пакет: обновляется независимо, устанавливается одной командой.

🎓 12 скиллов

Готовые «профессии» агента: автогенерация тестов, исправление багов, исследование репозиториев, генерация спецификаций и роадмапов.

📦 Бандлы и переносимость

Кастомизация через бандлы. Унифицированные пакеты легко передать в другие экземпляры FAN — настройка команды в один клик.

Всё устанавливается одной командой из FAN Store: fan store install <name>

Почему мы

Чем FAN отличается от облачных ассистентов

🔒 Данные не уходят

Сессии, код, настройки — локально. Нет облачного сервера FAN вообще.

🤖 Команда агентов

Не один чат, а координатор + 8 воркеров с верификацией каждого шага.

🖥 Мультиклиентность

TUI, браузер, IDE, скрипты — один рантайм, единый контекст.

💰 Бюджет под контролем

Лимиты, роутинг к дешёвым моделям, прозрачная статистика.

🏪 Расширяемость

FAN Store, MCP-интеграции, собственные скиллы и расширения.

📦 Нулевая установка

Standalone-бинарник: не нужен Node.js, установка одной строкой.
