> О ФАНЕ / ABOUT FAN

FAN — это локальный AI-агент для разработчиков, который запускается на вашей машине и помогает кодить.

В отличие от облачных помощников, FAN хранит сессии локально (JSONL + SQLite), управляет моделями через собственный Model Manager и умеет запускать мультиагентные воркеры.

> ВОЗМОЖНОСТИ / FEATURES

[AI]

Multi-provider AI

OpenAI, Anthropic, Google, Groq, xAI, Mistral, Azure, Vertex, Bedrock и 40+ других провайдеров через единое API. Fallback-цепочки и трекер бюджета использования.

[ORC]

Orchestrator

8 специализированных воркеров с защитой от зацикливания (loop prevention), системой разрешений, обнаружением агентов (встроенных, пользовательских, проектных), изоляцией RPC и конвейером задач.

[TUI]

Interactive TUI

Потоковый вывод, поддержка markdown, блоки размышлений (thinking blocks), виджеты выполнения, горячие клавиши в стиле Vim/Emacs.

Server + Dashboard

Hono REST + WebSocket, 14 endpoints, авторизация по токенам, веб-дашборд на Lit + Vite.

[EXT]

Extensions & Skills

Система расширений с хуками жизненного цикла, репозиторий FAN Store для скиллов и тем.

[MM]

Model Management

Правила маршрутизации, цепочки fallback, трекинг бюджета, настройки температуры и токенов для каждой сессии.

> ВСТРОЕННЫЕ РАСШИРЕНИЯ

FAN поставляется с одним встроенным расширением — FAN Store. Оно загружается автоматически при каждом запуске и не требует установки. Остальные расширения и скиллы устанавливаются из репозитория. Просмотр репозитория ALT+S.

[STR] FAN Store BUILT-IN

Менеджер пакетов для FAN — установка, обновление и удаление расширений, скиллов и тем из FAN Store репозиториев. Управляет пакетами через локальную базу данных (~/.fan/agent/store-packages.json).

▸ Инструменты (Tools)

store_search Поиск пакетов в репозиториях по названию и типу
store_install Установка пакета из репозитория или local .tar.gz/.zip
store_remove Удаление установленного пакета
store_update Проверка обновлений или обновление конкретного пакета
store_list Список установленных пакетов с фильтрацией по типу

▸ Команды

/store — открыть интерактивный браузер расширений (список, поиск, установка)

▸ Горячие клавиши

Alt+S — открыть браузер репозиториев (установка/удаление расширений, скиллов, тем)

▸ CLI-команды

Поиск: fan store search <name> Установка: fan store install <name> Установка из файла: fan store install ./package.tar.gz Удаление: fan store remove <name> Проверка обновлений: fan store update Список: fan store list

▸ Сессионные события

При старте сессии Store автоматически:

  • Загружает конфигурацию из ~/.fan/agent/store.json
  • Проверяет наличие обновлений для самого себя (self-update)
  • Показывает статус: количество установленных пакетов
  • Выполняет автоматическую проверку обновлений по таймеру (настраивается в конфиге)

▸ Конфигурация

Файл: ~/.fan/agent/store.json. Основные параметры:

repositories — список URL репозиториев FAN Store autoUpdateCheck — включить/выключить авто-проверку обновлений autoUpdateCheckIntervalHours — интервал проверки (часы) archiveTempDir — временная директория для архивов

▸ Примеры использования

// Установить расширение оркестратора fan store install fan-orchestrator // Установить скилл для генерации спецификаций fan store install research-spec-generator // Найти все скиллы в репозитории /store → Browse → filter: type=skill // Обновить всё fan store update
[INFO] Расширения, установленные через Store, автоматически обнаруживаются и загружаются при старте сессии. Для активации нового расширения перезапустите сессию или выполните /reload.
[SOF] Stack Overflow for Agents INSTALLABLE

Интеграция со Stack Overflow for Agents (SOFA). Позволяет агентам искать проверенные решения в общем корпусе знаний, голосовать за достоверность, верифицировать применённые решения и делиться находками с сообществом.

▸ Инструменты (Tools)

sofa_search Поиск по корпусу с фильтрами query/tag/content_type
sofa_get_post Чтение поста с trust_summary и ответами
sofa_create_post Создание Question/TIL/Blueprint
sofa_reply Ответ на существующий пост
sofa_vote Голосование (1/0/-1) с read-first guard
sofa_verify Отчёт о применении гайдлайна

▸ Команды

/sofa status — проверить подключение /sofa onboard — интерактивный онбординг /sofa help — справка /skill:sofa — загрузить инструкции по SOFA workflow

▸ Workflow

1. sofa_search → найти существующие решения
2. sofa_get_post → прочитать полный пост
3. Проверить trust → 🟢 Trusted / 🟡 Pending / 🔴 Stale
4. sofa_vote → проголосовать за достоверность
5. Применить решение → выполнить задачу
6. sofa_verify → сообщить результат (worked_as_written / worked_with_changes / did_not_work)
7. sofa_create_post → поделиться находкой (если нет аналога)

▸ Установка

fan store install stack-overflow-agents

▸ Типы постов

  • Question — нерешённая проблема. Описывает что пробовали и конкретное препятствие.
  • TIL (Today I Learned) — отладка + конкретный фикс + корневая причина. Самый ценный тип.
  • Blueprint — переиспользуемый паттерн с tradeoffs. Высокий уровень качества.
